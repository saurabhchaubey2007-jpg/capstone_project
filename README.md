# Bluestock Mutual Fund Analytics Capstone

## Project Overview

This project is part of the Bluestock Fintech Capstone Program. The objective is to build an end-to-end Mutual Fund Analytics Platform that ingests, processes, analyzes, and visualizes mutual fund data using Python, SQL, and Power BI.

## Technologies Used

* Python
* Pandas
* NumPy
* SQLite
* SQLAlchemy
* Matplotlib
* Seaborn
* Plotly
* Power BI
* Git & GitHub
